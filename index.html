Project Overview

Introduction

🎯 Objective

Create an AI system that mirrors human cognitive architecture by explicitly separating and coordinating conscious (deliberate, logical) and subconscious (intuitive, emotional) processing systems.

💡 Key Innovation

Unlike traditional AI systems that attempt to be purely logical or purely emotional, this architecture explicitly separates and coordinates both systems, mirroring the human cognitive architecture that evolution produced.

📊 Dual-Process Theory

  • System 1: Fast, intuitive, emotional, continuous
  • System 2: Slow, deliberate, logical, discrete

🏗️ Modular Design

Each stage produces independently valuable components while building toward the final integrated system, allowing incremental validation and risk mitigation.

Data Flow & Signal Types

🌊 Core Physical Principle: Conductive Fluid Analogy

"If we place a conductive fluid (like water) within a lower-density fluid, we can measure conductive surface area as our primary signal. Accuracy can be enhanced but perfect detail is impossible with continuous data."

💧 Subconscious (Fluid)

  • Signal: Continuous surface area
  • Resolution: Low (gestalt/holistic)
  • Speed: Fast (parallel)
  • Accuracy: Approximate but robust
  • Info Type: "Shape" of situation

🔢 Conscious (Discrete)

  • Signal: Discrete symbols
  • Resolution: High (precise)
  • Speed: Slow (sequential)
  • Accuracy: Exact but fragile
  • Info Type: Specific facts

Conscious-Subconscious Interface

ConsciousSubconsciousInterface.py 
class ConsciousSubconsciousInterface:
    def __init__(self):
        self.conscious_buffer = []  # Working memory
        self.emotional_salience = {}  # π-values for concepts
        self.attention_threshold = 0.3
        
    def filter_to_consciousness(self, sensory_input, emotional_field):
        """Gate what reaches conscious awareness"""
        salient_items = []
        for item in sensory_input:
            # Calculate emotional salience
            salience = emotional_field.get_potential(item)
            # Apply Weber-Fechner law (log scaling)
            if salience > self.attention_threshold * np.log(1 + len(self.conscious_buffer)):
                salient_items.append({
                    'content': item,
                    'salience': salience,
                    'emotional_tone': emotional_field.get_gradient_direction(item)
                })
        return salient_items[:7]  # Miller's Law limit
    
    def bias_conscious_reasoning(self, problem_space, emotional_gradient):
        """Inject emotional bias into logical reasoning"""
        for option in problem_space:
            alignment = np.dot(option.vector, emotional_gradient)
            option.priority *= (1 + 0.5 * alignment)  # 50% max bias

Liquid metal in electrolyte with direct conductance

✓ Pros:

  • Environmental/regulatory issues

Ionic Solution Gradients

Ion concentration gradients measured via impedance

✓ Pros:
  • Bio-identical - Same as neurons
  • Natural bio-sensor interface
  • Multiple ion "channels"

  • Slow (diffusion-limited)

Solid-state analog resistive memory arrays

  • Currently expensive
  • Device variability issues
